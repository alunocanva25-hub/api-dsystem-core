# DSYSTEM SERVER CORE V1.0.1.16 — DOMINGO ESPECIAL DS GO

A CORE passa a aceitar uma configuração especial de domingo enviada pelo DS Go.

Campos:
- `agendamento_online_domingo_ativo`
- `agendamento_online_domingo_horarios`
- `agendamento_online_domingo_max_clientes`

O domingo usa horários e capacidade próprios e não depende do expediente geral do Studio.

A autoridade é do DS Go; sincronização do Studio não sobrescreve esses campos.

Use no Render:
`APP_VERSION=1.0.1.16`
